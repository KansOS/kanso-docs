# QQOQCCP : mesure du point dur

| Question | Réponse |
| --- | --- |
| **Qui** | Elias pour les relevés et le launcher, Angel pour les indicateurs. Plus tard, des personnes accompagnées pendant les tests. |
| **Quoi** | Vérifier que le guidage désigne le bon bouton, ou s'abstient, dans des applications tierces, sur des démarches complètes. |
| **Où** | Sur le Honor (Android 14) et sur l'émulateur Android 16, dans les applications de l'annexe B. |
| **Quand** | 3 démarches complètes relevées avant le \[date à fixer\], puis les tests avec les personnes, pendant le test couleurs. |
| **Comment** | `releve.sh` et `analyse.py`, écran par écran. Les issues du guidage sont journalisées (désigné, introuvable, ambigu) et les fausses désignations sont vérifiées à la main. |
| **Combien** | 3 démarches de n écrans chacune, sur 10 applications prévues. Les seuils se déduisent de l'objectif « une démarche aboutit de bout en bout ». |
| **Pourquoi** | Fixer les seuils de la note sur des données plutôt qu'au jugé, puis décider si on vise toutes les applications ou une liste de démarches vérifiées. |
